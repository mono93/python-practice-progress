# Python Practice

A beginner-friendly Python practice repository organized by topic. Each folder contains example exercises and practice scripts designed to reinforce fundamental Python concepts.

## Current Practice Sets

- `01_basics/` - Basic Python syntax, printing, and simple operations
- `02_virtual/` - Virtual environment and project setup practice
- `03_data_types/` - Working with strings, numbers, lists, and other data types
- `04_conditionals/` - Conditionals, boolean logic, and decision-making
- `05_loops/` - Looping constructs, iteration, and loop-based exercises

## Usage

1. Open the repository in your code editor.
2. Run Python scripts using:
   ```bash
   python3 <path-to-script>.py
   ```
3. Add new practice files or folders under the appropriate topic.

## Adding New Practice Sets

Future practice sets can be added as new folders with a clear name and a brief description, for example:

- `06_functions/`
- `07_modules/`
- `08_file_io/`

Each folder should contain scripts that demonstrate and reinforce the relevant topic.

## Notes

- Keep file names descriptive and organized by chapter or exercise.
- Prefer simple, readable examples to support learning.
- This repository is intended for practice and experimentation with Python concepts.
